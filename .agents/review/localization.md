# Localization Review Checklist

Read `.agents/localization.md` first — it defines the pipeline and hard rules. Follow the
protocol in `.agents/review/README.md`.

## Strings in Code

* No hardcoded user-facing text. Every visible string goes through `__()`, `d__('domain', …)`,
  `n__()`, or `dn__()`.
* Msgids are written in English — they are both the key and the fallback.
* A msgid is a complete phrase, not a fragment glued to another fragment.
* Placeholders use `sprintf` style (`%s`, `%d`) instead of string concatenation, so
  translators can reorder words.
* Cross-domain strings use the explicit form (`d__('system', 'Page')`), not the module
  default.

## Markup Inside Strings

* A tag inside a msgid is fine when the sentence needs it, and the template prints it with
  `|raw`. A tag that appears only in a `msgstr` is a defect: autoescape prints it as text, and
  the fix belongs in the translation, not in the template.

## Generated Files

* `.lng.php` files were **not** edited by hand — they are generated by `composer translate`.
* `.pot` files were **not** edited by hand — they are generated by `composer translate-scan`.
* If code strings changed, the domain's `.pot` was regenerated.
* If a `.po` changed, the matching `.lng.php` was regenerated and both are committed
  together.

## `.po` Diffs

* Only the `msgstr` lines that were actually translated changed.
* The file was not reformatted, rewrapped, or reordered — a whole-file rewrite (typical of
  `polib`) is a `BLOCKER`, it makes the diff unreviewable.
* Only the languages explicitly requested were translated; no machine-translated extras.

## Registration

A new module needs **both**, otherwise its strings stay silently untranslated:

1. a `<domain>` entry in `translate.xml.dist` (`name`, `target`, `sourceDir`);
2. a `files` entry in `crowdin.yml` (`source: <domain>.pot`, `translation: %two_letters_code%.po`).

Verify both are present when the diff adds a module or a locale directory.

## Crowdin

* No Crowdin command (`make crowdin-*`) was run on the agent's own initiative — these are
  outward-facing and only run when explicitly asked.
* If `make crowdin-download` was run, `composer translate` followed it.
